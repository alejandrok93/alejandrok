★ AI AGENTS • 2026

Engage AI

Autonomous Outreach Agents for Law Firms

Agents that law firms configure to text new leads 24/7 in the firm's own voice. Each agent runs an observe → assess → act loop until it reaches its goal: qualify the lead, collect missing case details, or book a consultation. I built the scheduling and data-collection agents, plus the eval and simulation tooling that tests agent conversations before they reach a real lead.

▸ Three agent goals: qualification, data collection, scheduling
▸ Agents write collected answers back to the firm's matters & contacts
▸ LLM lead simulator + judge to regression-test conversations
▸ Extending from SMS to phone agents
TypeScript Mastra MCP Ruby on Rails React Evals

Merlin Copilot

A Conversational Assistant Over Live Firm Data

An assistant inside Lawmatics: staff describe what they need in plain language, and Copilot answers from live firm data, runs reports, and builds forms and automations. I worked on the tool layer the agent calls — tenant-scoped MCP tools that respect each user's permissions — and on sandboxed code execution for analysis that a single tool call can't answer.

▸ Agent sees only what the signed-in user can see
▸ Dozens of MCP tools over CRM, intake, and billing data
▸ Sandboxed code execution for multi-step analysis
TypeScript MCP GraphQL Ruby on Rails LLMs

// About

I'm a senior full-stack engineer based in Mexico City, with 10+ years building production software at places like Lawmatics and PwC.

For the past year and a half I've been building AI agents for law firms — agents that qualify leads, collect case details, book consultations, and answer questions over live firm data. Before that, I led mobile development for a major healthcare provider, managing 12 engineers and delivering to millions of users.

I also write Codigo Abierto — a newsletter about tech, AI, and the digital landscape in Mexico. Honest takes on what's actually happening, no hype.

When I'm not coding or writing, I'm probably reading about whatever new tech thing caught my attention this week.
